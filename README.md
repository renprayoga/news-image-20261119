# The World in One Image — 19 November 2026

One 1024×1024 image summing up 19 November 2026's world news: Grand Theft
Auto VI launching worldwide after a 13-year wait, the first-ever
Trump–Xi–Putin trilateral meeting in Shenzhen, the Gulf war widening as Iran
strikes U.S. bases in Kuwait and Bahrain, and Europe rallying for Ukraine in
Berlin. Drawn from scratch with PIL; `main.py` (stdlib only) copies the
finished `entry.png` to the output directory.

## Run

```sh
mkdir -p out && MAKEFUN_OUTPUT_DIR=out python3 main.py
```

To re-render the image from scratch (PIL required, deterministic, no network):

```sh
python3 draw.py
```
